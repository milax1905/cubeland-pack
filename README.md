# Cubeland - pack de mods

Pack HMCL du serveur prive **Cubeland** (Minecraft 1.19.2 / Forge 43.5.2).

Manifeste : https://pack.cubeland.fr/server-manifest.json
Serveur   : mc.cubeland.fr:3000

Ce depot est publie uniquement pour alimenter le launcher des joueurs du
serveur. Voir CREDITS.md pour la liste des mods et leurs auteurs.

Ne jamais editer server-manifest.json a la main : un fichier retire du
manifeste est supprime chez tous les joueurs. Utiliser publier-pack-cubeland.ps1.
